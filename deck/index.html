Three ways to scale the loop.

·Agent TeamsNamed specialists working at once — a builder, a designer, a tester — with one lead.
·WorkflowsThe steps written down once, so the AI runs them the same way every time.

Same loop — Context → Plan → Build → Ship — just bigger. Master it small first.

Name these, don't teach them deeply. Harness = the kitchen we've been building (your CLAUDE.md, plan mode, the checks) — Anthropic, OpenAI, everyone calls this the real skill now. Agent teams = flip one flag and Claude runs parallel specialists. Workflows = write the recipe once, run it hands-off. It's all the SAME loop, scaled. Reassure them: get one clean lap first; this is the growth path.
